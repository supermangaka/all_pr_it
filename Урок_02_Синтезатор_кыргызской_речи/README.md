# Синтезатор кыргызской речи

Программа озвучивает кыргызский текст. Можно выбрать женский или мужской голос и настроить скорость, паузы и тембр.

## Как запустить
- Открыть блокнот в Google Colab и выполнить ячейки по порядку.
- Появится ссылка вида gradio.live, по ней открывается сайт синтезатора.

## Что использовалось
- **Python и Google Colab:** среда, где всё запускается
- **Gradio:** интерфейс
- **Голоса Mamtil (Ulutsoft):** женский и мужской голос, модель Matcha-TTS
- **MMS-TTS (Meta):** модели для сравнения

## Что сделал я
- Собрал всё в одно приложение с выбором голоса
- Написал перевод чисел в слова: `25` → `жыйырма беш`
- Составил словарь произношения: `жыйырма` → `жырма`
- Проверил звучание на носителях языка

## Файлы
- `Исходники/app.py`: код синтезатора
- `Исходники/kyrgyz_tts_colab.ipynb`: тот же код для Google Colab
- `Исходники/requirements.txt`: нужные библиотеки

## Результат
Положи в эту папку файл проекта (блокнот `.ipynb` или `app.py`) и впиши сюда оценки носителей языка.
